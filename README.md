# Call Off — Grocery & Specialty Food Store Website

Repository: https://github.com/Abolfazl26s/call-off-demo

Call Off (branded on-site as "کال آف") is a multi-page, RTL (Persian) e-commerce website template
for a grocery and specialty food store, covering coffee, herbal teas, saffron, dried fruits and nuts,
and other food products.

---

## Overview

This project implements a full front-end for an online grocery shop: a hero slider homepage,
a mega-menu with product categories, tabbed best-seller product grids, a quick-view product modal,
wishlist and compare features, cart/checkout flow, and account/login pages.
The layout is right-to-left (RTL) in Persian, targeting Persian-speaking grocery shoppers.

---

## Features

- Homepage with hero image slider and category dropdown
- Mega-menu navigation with categorized sub-menus and promotional banner
- Tabbed best-seller product sections (All, Herbal Tea, Coffee, Dried Fruits & Nuts, Saffron)
- Product cards with hover images, sale/discount/new badges, and quick-view modal
- Wishlist, compare, and mini-cart dropdown with live item preview
- Shopping cart and checkout pages
- Login/account page
- Sticky header with search and category filter dropdown
- Mobile header with slide-out menu and social links
- Fully responsive layout

---

## Tech Stack

- HTML5 (static, multi-page)
- Bootstrap (RTL)
- Custom slider/range plugin CSS
- Flaticon (fi-rs) icon set for UI icons

---

## Getting Started

No build step is required — this is a static HTML/CSS/JS site.

1. Clone or download the repository
2. Open `index.html` directly in your browser, or serve the folder with a simple local server:

npx serve .

3. Visit the local URL shown in the terminal (or open `index.html` directly)
